# ☀️ SunCart – Summer Essentials Store 🌊

Welcome to **SunCart**, your ultimate modern destination for everything summer! From UV-protection shades to beach-ready outfits, we bring the sunshine to your shopping experience. This project was built as a high-performance eCommerce platform focusing on unique design, smooth animations, and secure authentication.

### 🔗 [**Live Site Link**](https://suncart-store-two.vercel.app/)

---

## 🌴 Key Features

*   **Summer-Themed UI**: A unique, "Sun-kissed" design using a vibrant color palette (`Sun`, `Tangerine`, `Dragonfruit`).
*   **Dynamic Products**: Browse a curated collection of summer essentials with real-time data filtering.
*   **Secure Authentication**: Full login and registration system powered by **BetterAuth**, including **Google Social Login**.
*   **Interactive Profile**: Users can view their profile data and update their information (Name & Image) seamlessly.
*   **Protected Routes**: Exclusive access to Product Details—only for our sun-club members!
*   **Lottie Animations**: Silky smooth, high-quality animations to enhance the summer vibe.
*   **Fully Responsive**: Perfectly optimized for Desktop, Tablet, and Mobile "Sun-seekers."

## 🛠️ Tech Stack

This project leverages the latest web technologies for speed and style:

| Technology | Purpose |
| :--- | :--- |
| **Next.js 15+** | React Framework with App Router for optimized routing. |
| **Tailwind CSS** | Utility-first CSS for the custom unique design. |
| **DaisyUI / HeroUI** | Component library for beautiful, accessible UI elements. |
| **BetterAuth** | Secure, modern authentication handling. |
| **Lottie React** | Lightweight, scalable vector animations. |
| **MySQL / Sequel Ace** | Robust backend database management. |
